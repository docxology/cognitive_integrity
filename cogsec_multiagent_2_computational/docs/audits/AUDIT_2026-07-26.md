### MISS-02 · No baseline comparator or null model exists anywhere; a 20-line regex detector beats the full CIF pipeline 3x on the paper's own evaluation set

**File:** `src/evaluation/__init__.py:9` · **Confidence:** confirmed · **Effort:** M

**Evidence**

`grep -rni 'negative control|null model|random_baseline|chance level|permutation test' src scripts tests manuscript` returns only rng.shuffle calls inside fold assignment — no comparator anywhere. The only 'baseline' in the paper is the all-zeros no-defense column: 06_discussion.md:90 'The baseline detection rate of 0.00 reflects the absence of CIF components'; src/analysis/game_theory.py:318-323 hardcodes the `no_defense` column to 0.00 for all six attack families. A baseline that is zero by construction cannot fail to be beaten.
REPRODUCED — measured the full pipeline and a trivial keyword detector on the IDENTICAL evaluation set used by `evaluate_component_subset` (98 stratified attacks, seed 42, + the 50 BENIGN_MESSAGES at src/ablation/runner.py:21):
  CIF FULL PIPELINE  TPR=0.1224  FPR=0.0000  Youden J=0.1224
  REGEX BASELINE     TPR=0.3776  FPR=0.0000  Youden J=0.3776
(baseline = one case-insensitive alternation over ~19 phrases: 'ignore (all|previous|prior) instruction', 'system prompt', 'jailbreak', 'bypass', 'sudo', 'pretend', ...). Caveat stated honestly: the corpus is template-generated, so a lexical baseline is partly matched to the generators — which is itself a finding, because it means either the corpus is too lexically stereotyped or CIF's semantic pipeline underperforms grep on it. Either reading must be in the paper.

**Failure scenario**

A reviewer runs any comparator — regex, bag-of-words logistic regression, an off-the-shelf prompt-injection classifier, or a random detector at matched flag rate — and finds it equals or beats the reported 12.2%/44.8% detection rates. **Fix**

Add a baseline/null-model suite and make it a first-class results section.
1. `src/evaluation/baselines.py` — public API:
   - `Protocol Detector: def score(self, payload: str) -> float; def detect(self, payload: str) -> bool`
   - `class RandomDetector(flag_rate: float, seed: int)` — flags uniformly at the CIF pipeline's empirical flag rate (the chance-level null).
   - `class KeywordDetector(patterns: Sequence[str] | None = None)` — the lexical floor; default pattern list frozen in the module, not tuned per corpus.
   - `class LengthDetector(threshold_chars: int)` and `class PerplexityFreeBagOfWords(...)` — cheap non-semantic floors.
   - `def permutation_null(detector, payloads, labels, n_perm: int = 10_000, seed: int = 42) -> NullResult` returning `(observed_J, null_mean_J, null_sd_J, p_value)` — label-permutation p-value for any detector, giving the paper actual p-values (see MISS-09).
   - `def compare_detectors(detectors: Mapping[str, Detector], attacks, benign) -> ComparisonTable` returning TPR, FPR, Youden J, MCC, balanced accuracy, and Wilson CIs (reuse the orphaned `statistics.confidence.wilson_ci`).
2. `scripts/run_baseline_comparison.py --seed 42 --output output/data` -> `output/data/baseline_comparison.json` with `data_origin: real_pipeline` and one row per detector including CIF.
3. Manuscript: new subsection in 05_results.md ('Comparison against non-CIF baselines') bound to that JSON via the MISS-01 claim registry; update the abstract to report CIF's margin over the strongest baseline, not over zero.
4. Tests: `tests/test_baselines.py` — (a) `RandomDetector` at flag_rate=p yields Youden J ~ 0 within CI (positive control that the null is a real null); (b) `permutation_null` on shuffled labels returns p > 0.05 and on a perfect detector returns p < 1e-3 (proves the test CAN reject and CAN fail to reject); (c) `compare_detectors` includes at least 3 non-CIF detectors — assert `len(rows) >= 4` so the comparison cannot silently become CIF-only.
