# Attack Corpus

950-attack corpus for security evaluation.

## Modules

| Module | Purpose |
|--------|---------|
| `corpus.py` | Corpus management |
| `templates.py` | Attack templates |
| `validation.py` | Attack validation |
| `generators/` | Category generators |

## Categories

- Prompt Injection (500)
- Trust Exploitation (200)
- Belief Manipulation (150)
- Coordination (100)
