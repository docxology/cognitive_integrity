# Architecture Adapters

Adapters for 4 production multiagent architectures.

## Supported Architectures

| Module | Architecture | Topology |
|--------|--------------|----------|
| `claude_code.py` | Claude Code | Hierarchical |
| `autogpt.py` | AutoGPT | Autonomous |
| `crewai.py` | CrewAI | Role-based |
| `langgraph.py` | LangGraph | Graph-based |
