# Interpretation and scope

The local fixture verifies the arithmetic for one declared set of values.
The non-amplification argument states the assumptions under which the
path rule has the same ordering for other valid inputs. Neither result
certifies the selection of the component scores and weights. Their reliability
requires separate justification for a concrete application.

The receipt records the implemented function's output and its input checks.
It makes no empirical claim about trustworthiness, detection effectiveness,
or deployed systems. Each of the three underlying publications has its own
evidence record and scientific scope.
