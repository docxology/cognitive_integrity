# Cognitive Integrity Framework - Part 4: Applications

This project contains the fourth manuscript in the Cognitive Integrity Framework series, focusing on applications across 10 critical domains.

## Structure

* `manuscript/`: Markdown source files for the paper.
* `src/`: Domain modeling code (if applicable).
* `tests/`: Verification tests.
* `output/`: Generated artifacts.

## Building

Run the PDF render pipeline:

```bash
./run.sh --render-pdf --project cogsec_multiagent_4_applications
```
