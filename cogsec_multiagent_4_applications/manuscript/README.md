# Manuscript Directory

This directory contains the Markdown source files for the paper "Cognitive Integrity in Critical Domains: A Multi-Sector Analysis."

## Structure

- `00_abstract.md`: Abstract and frontmatter.
- `01_*` to `05_*`: Main body sections.
- `S01_*`, `S02_*`: Supplements.
- `config.yaml`: Build configuration.
- `preamble.md`: LaTeX preamble for PDF generation.
