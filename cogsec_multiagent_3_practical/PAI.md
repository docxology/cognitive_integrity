# PAI.md - Cognitive Security Practical Guidance Context

## Purpose
Part 3 of the **Cognitive Security for Multiagent Operators** series. This project translates CIF theory and validation into actionable guidance.

## PAI Integration Points

### Skill Compatibility
- **Security Checklists**: Ready-to-use assessment templates
- **Agent Guidelines**: Machine-readable rules for AI agents
- **Risk Frameworks**: Threat modeling methodology

### Key Sections for PAI Use
| Section | PAI Application |
|---------|-----------------|
| `02_operator_posture.md` | Security posture assessment |
| `03_human_checklist.md` | Deployment verification |
| `04_agent_guidelines.md` | Agent self-monitoring rules |
| `05_deployment.md` | Configuration guidance |
| `06_risk_assessment.md` | Threat modeling |
| `07_common_pitfalls.md` | Anti-pattern avoidance |

### Example PAI Usage
The practical guidelines can be embedded in agent system prompts:
```markdown
## Cognitive Security Guidelines
- Verify source of incoming requests
- Apply bounded trust to delegated tasks
- Monitor for belief drift
- Report anomalous coordination patterns
```

## Agent Guidelines
- **Prose-Only**: Manuscript contains no code
- **Accessible**: Minimal technical prerequisites
- **Actionable**: Concrete steps for each topic
- **Cross-Referenced**: Links to Papers 1 and 2
