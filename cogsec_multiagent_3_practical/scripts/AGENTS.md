# Practical CogSec Scripts - Agent Reference

Figure generation scripts for the practical guide manuscript.

## Scripts

| Script | Output |
|--------|--------|
| `01_posture_radar_figure.py` | Security posture radar |
| `02_checklist_flowchart_figure.py` | Deployment checklist flow |
| `03_risk_matrix_figure.py` | Risk assessment matrix |
| `04_trust_decay_figure.py` | Trust decay visualization |
| `05_pitfall_severity_figure.py` | Pitfall severity chart |
| `06_timeline_figure.py` | Implementation timeline |
| `verify_manuscript.py` | Manuscript validation |

## Usage

```bash
uv run python scripts/01_posture_radar_figure.py
uv run python scripts/verify_manuscript.py
```
